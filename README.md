Аутентичный, нативный клиент легендарной калининградской пиццерии **«Папаша Беппе»**, созданный специально для старых устройств на базе **iOS 6**.

Никакого плоского дизайна. Никаких веб-вью. Только чистый скевоморфизм, градиенты, блики и олдскульный Objective-C код!

## ✨ Особенности

* **📱 Нативный Скевоморфизм:** Глянцевые кнопки (PJGlossButton), текстуры и анимации, полностью соответствующие гайдлайнам Apple 2012 года.
* **🌐 Умный Обход Блокировок:** Современные рестораны скрывают свои API за Cloudflare и SSR. Мы это обошли! Специальный скрипт на базе GitHub Actions каждые 12 часов скрапит актуальное меню с официального сайта и формирует легкий JSON.
* **🚀 Идеальная Производительность:** Старый iPhone или iPod Touch не давится тяжелым парсингом веб-страниц — он получает готовую, легковесную выжимку меню напрямую с GitHub.
* **📞 Заказ в один клик:** Собрал корзину? Нажимай «Оформить заказ» и приложение бесшовно перебросит тебя в звонилку с уже набранным номером доставки!

## 🛠 Архитектура

Так как сайт Папаши Беппе использует Nuxt 3 и скрывает данные внутри зашифрованных блоков (без открытого REST API), приложение работает через прокси-скрапер:
1. scrape_beppe.yml на GitHub Actions заходит на сайт.
2. Парсит HTML-дерево и достает актуальные цены/названия.
3. Сохраняет их в menu.json в этом репозитории.
4. Клиент на iOS 6 просто делает легкий GET запрос к aw.githubusercontent.com.

## 📦 Установка

Проект собирается через **Theos**. Сборка настроена в CI/CD (GitHub Actions).
Просто скачайте последний скомпилированный .deb пакет из вкладки **Actions** и установите его на ваш Jailbroken девайс через iFile или Filza.
